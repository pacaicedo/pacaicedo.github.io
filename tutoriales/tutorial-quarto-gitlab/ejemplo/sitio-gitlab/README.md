# sitio-gitlab

Sitio Quarto con la marca «Del dato a la causa», listo para GitLab Pages.

- `quarto preview` para verlo en local.
- Cada push a la rama por defecto lo renderiza y publica `.gitlab-ci.yml`.
- Antes del primer push, ajusta `site-url` en `_quarto.yml` con la dirección que
  muestra GitLab en **Deploy > Pages**.

Detalles en el tutorial `tutorial-quarto-gitlab.html`.
